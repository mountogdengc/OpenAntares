# Fresh read-only builder report — 2026-10-27

1. **High — What happens when ordinary construction or a mandatory safety split would exceed the 64-fleet cap?** FLT-002 requires every vessel to belong to a fleet, creates singleton fleets on ordinary completion, and mandates safety splits. A campaign with 64 fleets could therefore make a normal production completion or emergency departure violate validation. The plan needs a defined overflow policy, especially whether the limit constrains only discretionary commands or can block production/safety.

2. **High — What exact construction authority does a request enable when a colony has construction automation off but retains an assigned template?** FLT-003 promises “queue-only execution” while retaining that template. Under the existing colony contract, queue-only execution means construction enabled with no template; otherwise template suggestions become eligible when explicit work is unavailable. Should request execution temporarily suppress the stored template and restore the previous construction switch afterward, or does accepting the request explicitly authorize ongoing template construction? This determines the controller state and whether finite ship requests can inadvertently authorize unrelated buildings.

3. **High — Does a Missing slot prevent request completion?** FLT-003 says lost/detached hulls leave Missing slots requiring an explicit amendment, but also says the request completes when “all surviving authorized slots arrive.” If one of four hulls is lost and three arrive, those clauses permit different completion and XP outcomes. The completion predicate must distinguish blocked fulfillment from a deliberately approved reduced quota.

4. **Medium — What happens to an embarked officer and fleet when its flagship is consumed by successful colony founding?** M8 permits colony vessels and officers aboard flagships; existing founding consumes the vessel. FLT-006 defines actual destruction, but founding is successful consumption rather than an officer-loss event. The plan needs to know whether the officer posts at the new colony, transfers to another co-located member, or must disembark before founding, plus how an emptied fleet is retired. This also needs to respect a Wenth appointment’s original source-body identity.
