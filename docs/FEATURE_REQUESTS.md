# Future feature requests

These requests preserve ideas for later consideration. They are outside the current milestone; recording them does not select a design or schedule implementation.

## FR-001: Peaceful mode

- **Status:** Deferred
- **Requested by:** Project owner, 2026-10-24
- **Intent:** Offer an enjoyable way to explore and develop a spacefaring civilization peacefully, without combat.

Two possible directions remain open:

1. The regular game with combat disabled, potentially retaining other civilizations and peaceful interaction.
2. A solo experience centered on building and managing an empire, with a SimCity-like appeal. SimCity is a loose reference for the experience, not a prescribed set of mechanics.

The central design question is what sustains interesting decisions, progression and long-term engagement without warfare or rival empires. Whether to adapt the normal game or create a distinct solo mode remains undecided; objectives, challenge and pacing should be explored when this request is revisited.

**Scope:** Explicitly out of scope for current work. No design or implementation is requested now, and no release or milestone is assigned.
