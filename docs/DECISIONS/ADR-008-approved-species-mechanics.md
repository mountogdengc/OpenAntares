# ADR-008: Approve the classic space-opera species mechanics

Date: 2026-10-23. **Status: Accepted design; separate implementation plan requested, execution not started.**

## Owner decision

The owner said: “Approved. Go ahead and create the species-mechanics implementation plan with that classic Master of Orion 2 direction.” This accepts the complete [species specification](../superpowers/specs/2026-10-23-species-mechanics-design.md), including its four owner-review groups. ADR-007 remains the historical draft authorization; this record supplies the subsequent design approval.

## Accepted scope

Keep Peldra, Harl, Sulan and Wenth as memorable classic space-opera aliens. Humanoid animals/monsters and fanciful biology are welcome; respect real peoples, cultures and religions. Familiar population units need no compulsory cohort/reproductive model; Wenth uses lobes. Culture remains descriptive.

Accept the exact profiles and expedition tables: viable supported Peldra start, rapid Harl recovery/small parties, Sulan native Shelf Sea versus sealed harbor investment/capacity, Wenth full-current-capacity maturity and conserved three-lobe seeds, including extension raising maturity to eight. Accept ordinary worker support, aggregate fixed-point factors, snapshot timing and shared explanations. Harl is the visible new-game default; new campaigns use rules 3/schema 4, with the explicit seven supported version pairs and no conversion of old campaigns.

## Consequences and limits

M3-D is complete for design; SPC-AC-010 owner review is satisfied. REQ-016 remains In Progress because no species functionality has been implemented or verified. The separate [ten-task implementation plan](../superpowers/plans/2026-10-23-species-mechanics.md) is written/self-reviewed and awaits owner review before execution. The prior Native preference persists without requiring another method choice; it does not substitute for review of this new plan.

Preserve the owner's uncommitted roster/research files, approved architecture, integrated working code, genuine old saves and recovery evidence. No gameplay/core-content edits, dependency changes, migration, new art or broad later systems are authorized by this planning task. The deferred human session remains Deferred; no balance, usability or release pass is invented.
