# ADR-030: Original identity and current design record

Date: 2026-11-16.

**Status:** Adopted for documentation framing and reconciliation. Supply/migration gameplay defaults remain Proposed.

## Context

The owner approved reconciling the design record and drafting the supply/migration specification, adding: "we might need to take out references to masters of orion since this has become its own thing". The existing charter already requires an original setting, systems and visual identity. Current documents still contain predecessor-based creative framing and First Playable/older-milestone next actions despite later implemented systems.

## Decision

Describe OpenAntares directly as an original space strategy game. Remove predecessor comparisons from active identity and creative guidance while retaining the colorful, fanciful space-opera brief and respect for real peoples/cultures/religions. Update current species guidance and globe style to this framing without changing approved mechanics.

Preserve dated owner quotations, source titles, research, reference screenshots, licensing/provenance and original evidence. They document how earlier work happened; they are not current branding or requirements to imitate another game. Current guidance supersedes their identity framing without rewriting that history.

Use DESIGN_GUIDE.md as the readable current overview, the charter as product intent, subsystem specifications as versioned detailed contracts and PROJECT_STATUS.md as the inspected-source/current-work record. Prepend explicit current summaries to the requirements, acceptance and continuation indexes, and label retained checkpoint bodies as historical. Do not change parent acceptance totals without new qualifying evidence.

Draft the supply/migration proposal from the owner's November 12 direction. Mark assistant-selected resources, quantities, policies, migration exceptions and staged boundaries as proposals. Owner authorization to write the draft is not gameplay approval or permission to implement, commit, merge, push or release.

## Consequences

Contributors can begin from current design and source status instead of following stale historical next actions. Research remains auditable. Existing game rules, saves, assets, source code, tests and acceptance evidence are unchanged by this reconciliation. The current v2 globe appearance acceptance is distinguished from its pending Windows performance verification and overall player acceptance.
