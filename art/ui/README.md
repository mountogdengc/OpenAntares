# OpenAntares command-console UI art

Original geometric frames and symbols authored for OpenAntares on2026-11-08. These files are newly constructed chamfered polygons, bevels and line drawings; no commercial-game artwork or third-party UI kit is used.

All PNG and SVG artwork in this directory is dedicated under CC0 1.0 Universal: https://creativecommons.org/publicdomain/zero/1.0/ . To the extent possible under law, the contributors waive copyright and related rights in this original artwork. This dedication does not apply to the separately licensed font files.

Frames are delivered at2x logical size. Use nine-patch borders; do not stretch decorative corners. SVG icons have a24-unit viewbox and48-pixel default size. UI imports use no mipmaps. The texture/icon resources are referenced by the shared theme, never hard-coded in game components.

Font provenance, versions, original URLs and SHA256 values are recorded in asset-manifest.json. Each font retains its unmodified SIL OFL1.1 text and upstream metadata under art/fonts. The asset authoring source is retained in reports/visual-overhaul-execution/prepare-assets.py.
