# Licensing

OpenAntares uses different licenses for different kinds of content.

| Content | License | Full text |
| --- | --- | --- |
| Source code (scripts, scenes, project and build configuration) | MIT License | [LICENSE](LICENSE) |
| Original game assets (art, audio, music, fonts, and other media) | CC0 1.0 Universal | [LICENSE-ASSETS](LICENSE-ASSETS) |
| Documentation (everything under `docs/`, plus Markdown files such as this one) | CC BY 4.0 | [LICENSE-DOCS](LICENSE-DOCS) |

Game content data files (technologies, buildings, species traits, and other definitions) are treated as source code and use the MIT License.

## Exceptions

An asset or file that uses a different license must say so, either in a note next to the file or in the list below.

Third-party components keep their own licenses. There are currently none in the repository.

The OpenAntares logo and title art in `art/branding/` are original assets under CC0 1.0, like the other game assets.

The original planetary style palettes and structure catalogue in `art/planets/planet_styles.json` are CC0 assets. The procedural renderer is original MIT source; no third-party art, library or shader was added.

## Contributing

By contributing, you agree that your contributions are released under the license that covers that kind of content, as described above.

The project does not accept copyrighted assets from other commercial games.
